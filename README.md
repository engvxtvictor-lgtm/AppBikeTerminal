# AppBike Terminal

## 📋 Sobre o projeto

O AppBike Terminal é um sistema de terminal de autoatendimento para uma estação de bicicletas compartilhadas. O terminal permite ao usuário informar e confirmar os dados de sua corrida antes da retirada da bicicleta.

O projeto está sendo desenvolvido em Java como atividade prática da disciplina de Programação Orientada a Objetos.

## 🎯 Objetivo

Desenvolver um terminal de autoatendimento para o sistema AppBike, permitindo ao usuário informar e confirmar os dados de sua corrida antes da retirada da bicicleta.

O projeto tem como objetivo aplicar, na prática, conceitos de Programação Orientada a Objetos utilizando Java e o ambiente Apache NetBeans.

## 🛠️ Tecnologias utilizadas

- Java
- Apache NetBeans
- Apache Maven
- Git
- GitHub

## 📌 Funcionalidades

### Implementadas

- Inicialização do sistema no console
- Definição do nome da estação
- Definição da quantidade de bicicletas disponíveis
- Definição da tarifa por minuto
- Exibição dos dados da estação no console

### Em desenvolvimento

- Entrada da matrícula do usuário
- Entrada da estação de destino
- Entrada do tempo estimado de uso
- Cálculo do valor da corrida
- Geração de recibo formatado
- Implementação do desconto para usuários elegíveis
